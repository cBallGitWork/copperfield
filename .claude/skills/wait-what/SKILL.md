# Say it again, plainly

Craig did not follow the last message. Re-pitch it; do not defend it.

1. Lead with the one thing he needs to know or decide, in one sentence.
2. Use the glossary's words (`docs/providers/README.md` §Glossary). Translate the repo's
   stylised phrasing: "priced nowhere" is "no league scores it"; "the served league" is
   "the real league the app shows".
3. No metaphor the message did not need ("load-bearing", "seam", "frontier", "lands").
   Name the file, the screen or the number instead.
4. Three to six short lines. If a choice is involved, list the options and your pick.
5. Add nothing new. If re-saying it shows the original was wrong, say that first.
